MACOS SUPPORT
Run: chmod +x check-system.sh && ./check-system.sh
Install Tailscale from its official source and authenticate to your own private network.
For incoming access to a Mac, deliberately enable Screen Sharing or Remote Management in System Settings and restrict access to trusted users.
For connecting from a Mac to a Windows host, use a compatible RDP client.
This script is read-only; it does not change privacy settings or enable remote access.
