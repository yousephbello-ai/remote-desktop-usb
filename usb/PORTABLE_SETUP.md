
# Portable USB Setup

## Requirements
- A USB drive with enough free space
- Python 3 installed on the target computer
- Permission to run software on that computer

## Setup
1. Copy the repository files to your USB drive.
2. Keep `main.py`, `config.json`, and the launcher files together.
3. On Windows, double-click `start-windows.bat`.
4. On Linux, open a terminal and run `./start-linux.sh` after making it executable.

## Important
This version is a starter application, not a complete remote desktop system.

It does not yet provide remote screen sharing or remote control.

Never store passwords, private keys, or access tokens directly in this repository.

## Bootable USB
A bootable version will require a separate operating system image and USB creation process. Back up the USB drive before creating bootable media because that process may erase its contents.
