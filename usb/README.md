
# USB Setup Guide

## Portable USB mode

1. Use a USB drive with sufficient free space.
2. Copy the project files onto the drive.
3. Install a compatible Python version on the target computer.
4. Run `python main.py` from the project directory.

## Bootable USB mode

Bootable mode is planned for a later stage. It will require a suitable operating system image and USB creation process.

## Security

Only use this toolkit on computers you own or have permission to administer. Remote access must require authentication and user consent.
