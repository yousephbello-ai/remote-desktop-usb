BOOTABLE USB OPTION (RUFUS)
This repository contains instructions only, not an ISO or bootable image.
Rufus writes a genuine operating-system image to USB and may erase the drive. Obtain the image only from its official publisher and verify it.
A booted live OS is separate from the installed OS and does not automatically enable remote access on that installation.
Mac boot media has model- and architecture-specific requirements; Rufus is not a universal Mac boot-media solution.
Never use boot media to bypass another person's login or access controls.
